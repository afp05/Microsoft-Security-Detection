# Lab Setup

## Objective

Build a Microsoft security lab for endpoint incident investigation, KQL hunting and Sentinel detection engineering.

## Components

- Microsoft Azure tenant
- Resource Group: rg-cyber-lab
- Log Analytics Workspace: law-defender-sentinel-lab
- Microsoft Sentinel
- Microsoft Defender portal
- Windows endpoint for testing

## Planned Data Sources

- Microsoft Defender XDR incidents
- Defender for Endpoint telemetry
- DeviceProcessEvents
- DeviceNetworkEvents
- DeviceFileEvents
- DeviceRegistryEvents

## Portfolio Goal

Demonstrate practical skills in:

- endpoint alert triage
- process tree analysis
- suspicious command-line investigation
- KQL hunting
- Sentinel analytics rule creation
- MITRE ATT&CK mapping
- malware triage
